# 🌟 LumiKids v2.5 - عالم الاكتشاف الذكي
تطبيق تعليمي وتفاعلي ثنائي اللغة (العامية المصرية والفرنسية) مصمم للأطفال، يعمل بالكامل دون إنترنت (PWA + IndexedDB + LocalStorage).

## ✨ المميزات الرئيسية
- **20 لعبة تعليمية × 10 مستويات (200 مرحلة):** تغطي الذاكرة، المنطق، البرمجة المبسطة، التناظر البصري، اللغة الفرنسية، وتأليف القصص.
- **استوديو صوت العائلة:** تسجيل عبارات التشجيع، شرح الألعاب، القصص، والمفردات بصوت الأب والأم.
- **تعدد الملفات الشخصية (Multi-Profiles):** ملفات مستقلة لكل طفلة بالنجوم، الملصقات، ومؤشرات الذكاء.
- **خريطة المغامرات اليومية الذكية:** ترشح 4 مهام يومية لتقوية المهارات الأقل درجة.
- **لوحة تحكم الوالدين:** تحليل القدرات الذهنية الخمس، سجل الجلسات بالوقت والتاريخ، وتصدير تقارير PDF للطباعة.
